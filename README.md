### 🇷🇺 Русский

Легковесный и производительный агент для мониторинга системных ресурсов серверов на базе Windows Server / Windows Desktop. Разработан на языке Go с использованием низкоуровневых вызовов Win32 API без тяжелых сторонних библиотек. Работает в фоне как полноценная служба Windows (Windows Service) и является частью экосистемы HostPulse CRM.

### ✨ Особенности

* ⚡ **Минимальное потребление ресурсов**: благодаря компиляции в чистый бинарный код, агент потребляет не более 15-20 МБ оперативной памяти и имеет околонулевую нагрузку на CPU хост-машины.
* 🛠 **Автоматическое развертывание**: устанавливается и настраивается в фоне одной командой через PowerShell без необходимости ручной настройки реестра.
* 📦 **Управление через NSSM**: для обеспечения стабильности и автоматического перезапуска при сбоях агент упаковывается в фоновую службу с помощью встроенной утилиты NSSM (Non-Sucking Service Manager).
* 🔒 **Безопасность и прозрачность**: код полностью открыт. Агент собирает исключительно телеметрию производительности железа и не имеет доступа к вашим персональным файлам.

### 📊 Собираемые метрики

Агент отправляет данные в CRM каждые 10 секунд:

1. **cpu_usage (%)** — общая загрузка процессора (усредненная по всем логическим ядрам).
2. **ram_usage (%)** — процент использования оперативной памяти.
3. **disk_usage (%)** — процент заполнения основного системного диска (`C:`).
4. **disks (Array)** — расширенная детальная статистика по каждому логическому диску в системе отдельно (`C:`, `D:` и т.д.) с указанием общего объема, занятого места в ГБ и процента использования.

### 🛠 Быстрый запуск

Рекомендуемый способ запуска — использование автоматического скрипта установки, который скачивает бинарник, скомпилированный через GitHub Actions, и регистрирует службу Windows.

Вам достаточно открыть командную строку (`cmd.exe`) или PowerShell **от имени Администратора** и выполнить одну команду (все переменные и UUID генерируются вашей CRM):

```powershell
powershell -Command "Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.SecurityProtocolType]::Tls12; $cmd = [scriptblock]::Create((New-Object System.Net.WebClient).DownloadString('https://githubusercontent.com')); & $cmd -URL 'https://your-crm-domain.com' -TOKEN 'your-server-uuid-token' -PASSWORD 'your-secure-password'"
```

**Важно:** Запуск строго от имени Администратора обязателен, так как скрипту необходимы права для создания системной службы в директории `C:\Program Files\HostPulse`.

### ⚙️ Переменные окружения

Переменные прописываются утилитой NSSM напрямую в контекст службы (AppEnvironmentExtra):
* `HOSTPULSE_METRICS_URL` — Прямой API эндпоинт вашей CRM для приема JSON-пакетов метрик.
* `HOSTPULSE_TOKEN` — Уникальный UUID идентификатор сервера, сгенерированный в CRM.
* `HOSTPULSE_SECRET` — Секретный пароль для валидации удаленных команд (не сохраняется in CRM).

### 🇬🇧 English

A lightweight and high-performance agent for monitoring system resources of Windows Server and Windows Desktop machines. Developed in Go using low-level Win32 API calls without heavy third-party dependencies. It runs seamlessly in the background as a native Windows Service and is a core part of the HostPulse CRM ecosystem.

### ✨ Features

* ⚡ **Ultra-low Resource Footprint**: Due to pure Go compilation, the agent consumes less than 15-20 MB of RAM and has near-zero CPU overhead.
* 🛠 **Automated Deployment**: Installed and configured in the background with a single PowerShell command, completely bypassing manual registry tweaks.
* 📦 **NSSM-managed Service**: Packaged as a reliable background service via embedded NSSM (Non-Sucking Service Manager) to guarantee automatic restarts on failure.
* 🔒 **Secure & Transparent**: Fully open-source. The agent strictly collects hardware performance telemetry and has no access to your personal data or filesystem.

### 📊 Collected Metrics

The agent pushes telemetry to the CRM every 10 seconds:

1. **cpu_usage (%)** — Total CPU load (averaged across all logical cores).
2. **ram_usage (%)** — Percentage of used RAM.
3. **disk_usage (%)** — Percentage of root system partition (`C:`) disk usage.
4. **disks (Array)** — Detailed extended telemetry per each logical drive in the system (`C:`, `D:`, etc.), including total size, used space in GB, and usage percentage.

### 🛠 Quick Start

The recommended installation method is using the automated setup script that pulls the executable binary pre-built via GitHub Actions and registers the Windows service.

Simply open Command Prompt (`cmd.exe`) or PowerShell **as Administrator** and execute a single command (all arguments are automatically generated by your CRM):

```powershell
powershell -Command "Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.SecurityProtocolType]::Tls12; $cmd = [scriptblock]::Create((New-Object System.Net.WebClient).DownloadString('https://githubusercontent.com')); & $cmd -URL 'https://your-crm-domain.com' -TOKEN 'your-server-uuid-token' -PASSWORD 'your-secure-password'"
```

**Important:** Running explicitly as Administrator is strictly required since the script needs elevated privileges to create a system service inside `C:\Program Files\HostPulse`.

### ⚙️ Environment Variables

Variables are securely injected by NSSM directly into the service runtime context (`AppEnvironmentExtra`):
* `HOSTPULSE_METRICS_URL` — Direct API endpoint of your CRM to accept JSON metric payloads.
* `HOSTPULSE_TOKEN` — Unique UUID server identifier generated by the CRM.
* `HOSTPULSE_SECRET` — Secret password for validating remote commands (not stored in the CRM).

### 🇰🇿 Қазақша

Windows Server / Windows Desktop негізіндегі серверлердің жүйелік ресурстарын бақылауға арналған жеңіл және өнімділігі жоғары агент. Ауыр сыртқы кітапханаларсыз, Win32 API төмен деңгейлі шақыруларын қолдану арқылы Go тілінде жасалған. Фондық режимде толыққанды Windows қызметі (Windows Service) ретінде жұмыс істейді және HostPulse CRM экожүйесінің ажырамас бөлігі болып табылады.

### ✨ Ерекшеліктері

* ⚡ **Ресурстарды минималды тұтыну**: таза Go кодина компиляциялануының арқасында агент ең көбі 15-20 МБ жедел жадты тұтынады және CPU-ға дерлік жүктеме түсірмейді.
* 🛠 **Автоматты түрде орнату**: реестрді қолмен баптау қажеттілігісіз, PowerShell арқылы бір командамен фондық режимде орнатылады және конфигурацияланады.
* 📦 **NSSM арқылы басқару**: қателіктер кезінде автоматты түрде қайта іске қосылуды қамтамасыз ету үшін агент кірістірілген NSSM (Non-Sucking Service Manager) утилитасы көмегімен жүйелік қызметке оралады.
* 🔒 **Қауіпсіздік пен ашықтық**: код толықтай ашық. Агент тек жабдықтың өнімділік телеметриясын жинайды және сіздің жеке файлдарыңызға қолжетімділігі жоқ.

### 📊 Жиналатын метрикалар

Агент әр 10 секунд сайын CRM-ге деректерді жіберіп отырады:

1. **cpu_usage (%)** — процессордың жалпы жүктемесі (барлық логикалық ядролардың орташа мәні).
2. **ram_usage (%)** — жедел жадты пайдалану пайызы.
3. **disk_usage (%)** — негізгі жүйелік дисткинің (`C:`) толу пайызы.
4. **disks (Array)** — жүйедегі әрбір логикалық диск (`C:`, `D:` және т.б.) бойынша жалпы көлемін, ГБ-тағы бос емес орнын және пайдалану пайызын көрсететін кеңейтілген егжей-тегжейлі статистика.

### 🛠 Жылдам іске қосу

Ұсынылатын іске қосу әдісі — GitHub Actions арқылы автоматты түрде жиналған бинарлық файлды жүктеп алатын және Windows қызметін тіркейтін автоматты орнату скриптін пайдалану.

Пәрмен жолын (`cmd.exe`) немесе PowerShell-ді **Әкімші атынан (Run as Administrator)** ашып, келесі бір пәрменді орындау жеткілікті (барлық айнымалылар CRM арқылы автоматты түрде жасалады):

```powershell
powershell -Command "Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.SecurityProtocolType]::Tls12; $cmd = [scriptblock]::Create((New-Object System.Net.WebClient).DownloadString('https://githubusercontent.com')); & $cmd -URL 'https://your-crm-domain.com' -TOKEN 'your-server-uuid-token' -PASSWORD 'your-secure-password'"
```

**Маңызды:** Әкімші атынан іске қосу міндетті болып табылады, өйткені скриптке `C:\Program Files\HostPulse` директориясында жүйелік қызметті құру үшін жоғарылатылған құқықтар қажет.

### ⚙️ Орта айнымалылары

Айнымалылар NSSM утилитасымен тікелей қызметтің іске қосылу контекстіне жазылады (`AppEnvironmentExtra`):
* `HOSTPULSE_METRICS_URL` — Метрикалардың JSON пакеттерін қабылдауға арналған CRM-нің тікелей API эндпоинті.
* `HOSTPULSE_TOKEN` — CRM ішінде жасалған сервердің бірегей UUID идентификаторы.
* `HOSTPULSE_SECRET` — Қашықтағы пәрмендерді тексеруге арналған құпия пароль (CRM ішінде сақталмайды).
